sudo
gives command admin permission

sudo apt install <app>
best to do sudo apt update before this to keep programs up to date
download and install new tools

heavy update flow:

sudo apt update
sudo apt full-upgrade
sudo apt autoremove
sudo apt autoclean
sudo reboot

light update flow:

sudo apt update
apt list --upgradable
sudo apt upgrade
sudo apt autoremove

apt policy <app>
check if app exist and what version can kali download based on app
installed: if version. installed; else not installed
candidate: possible version to be installed
