git init
start up a new github repo

git status
check status

git remote -v
check which github repo is connected

git remote add origin <repo link>
connect repo to github...

git clone <repo link>
downloads the repo

git fetch 
downloads the repo without integrating to the timeline

git merge origin/main
merges current files to repo timeline

git diff
check files not staged by git add .

git log --oneline
check repo timeline 

git pull
fetch + merge once you already have the repo
